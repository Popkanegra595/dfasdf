# ПОЛКА — статическая библиотека файлов

Сайт-полка, с которой можно скачивать файлы. У каждого файла есть обложка, описание, категория, теги, версия и размер. Всё работает на чистом HTML, CSS и JavaScript — без сборки, базы данных и серверной части.

## Что внутри

- `index.html` — публичная библиотека с поиском, фильтрами, сортировкой и карточкой файла.
- `admin.html` — панель управления: загрузка файлов, обложек и описаний, черновики, редактирование, удаление и публикация.
- `data/library.js` — опубликованный каталог файлов.
- `assets/css/main.css` — стили сайта и общие компоненты.
- `assets/css/admin.css` — стили панели управления.
- `assets/js/` — иконки, локальное хранилище и логика страниц.
- `assets/covers/` — обложки демо-файлов.
- `files/` — демо-файлы для скачивания.
- `assets/fonts/` — локальные шрифты Manrope и Unbounded. Внешние CDN не используются. Шрифты распространяются по лицензии SIL OFL 1.1, тексты лицензий лежат рядом с файлами шрифтов.

Все иконки — инлайн-SVG. Эмодзи в интерфейсе нет.

## Запуск

Открыть `index.html` напрямую в браузере можно, но для полноценной работы (IndexedDB, скачивание файлов, публикация) лучше запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Затем открыть:

- `http://localhost:8000/` — сайт;
- `http://localhost:8000/admin.html` — панель управления.

## Как добавить файл

1. Откройте `admin.html`.
2. Перетащите файл в блок «Что добавляем?».
3. Название, категория и размер подставятся автоматически. Их можно изменить.
4. Загрузите обложку (необязательно) и заполните описание, теги, версию.
5. Нажмите «Сохранить на полку». Черновик сохранится в IndexedDB текущего браузера.
6. Добавленный файл появится в локальной ленте панели, а на главной странице — после её обновления. Черновик виден только в этом браузере.

## Как опубликовать изменения

Статический сайт не может сам записывать файлы на сервер, поэтому публикация сделана через обмен файлом данных:

1. В панели управления нажмите «Опубликовать».
2. Скачайте `library.js`.
3. Замените им файл `data/library.js` в папке сайта.
4. Загрузите обновлённую папку на хостинг.
5. Обновите страницу — файлы увидят все посетители.

Локальные файлы при экспорте встраиваются в `library.js` как data URL. Поэтому один файл данных содержит и описания, и сами файлы, и обложки. Для очень больших файлов удобнее хранить их отдельно в `files/` и указывать путь вручную.

## Ручное добавление файла

Можно не использовать панель, а положить файл и обложку в папки и добавить запись в `data/library.js`:

```js
{
  id: 'my-file',
  title: 'Мой файл',
  description: 'Короткое описание файла.',
  category: 'Документы',
  tags: ['шаблон', 'документ'],
  fileName: 'my-file.pdf',
  fileSize: 1048576,
  fileType: 'application/pdf',
  fileUrl: 'files/my-file.pdf',
  coverUrl: 'assets/covers/my-cover.svg',
  version: '1.0',
  createdAt: '2026-11-24T10:00:00+03:00',
  updatedAt: '2026-11-24T10:00:00+03:00'
}
```

Добавьте объект в массив `items`. После этого запись появится на сайте без локального черновика.

## Где хранятся черновики

Черновики хранятся в IndexedDB браузера, в базе `polka-library`. Они не отправляются на сервер. Очистка данных сайта в браузере удалит локальные черновики, поэтому перед важными изменениями лучше сразу публиковать `library.js` и сохранять его копию.

## Особенности

- Поиск по названию, описанию, категории, тегам и имени файла.
- Фильтры по категориям, сортировка по дате, названию и размеру.
- Переключение вида: сетка или список.
- Светлая и тёмная темы, выбор сохраняется.
- Адаптивная вёрстка для телефона и планшета.
- Модальная карточка файла с обложкой и характеристиками.
- Локальные SVG-иконки и шрифты, без внешних зависимостей.
- Ограничение загрузки через панель: 100 МБ на файл, 12 МБ на обложку.

## Хостинг

Сайт можно разместить на любом статическом хостинге: GitHub Pages, Netlify, Cloudflare Pages, Vercel, обычный shared-хостинг. Просто загрузите содержимое папки. Для GitHub Pages подойдёт загрузка в корень репозитория или в папку `docs/`.

## Демо-файлы

В `files/` лежат шесть демонстрационных файлов: бренд-кит, чек-лист, дизайн-токены, набор иконок, контент-план и шаблон портфолио. Их можно заменить своими — структура каталога от этого не изменится.
